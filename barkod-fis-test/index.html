🧪 Barkod Okuma & Fiş Testi

Ertek Finans'tan bağımsız — sadece test amaçlı. Stok takibi yapılmaz.

1Tanılı Barkod Listesini Yükle
Test için kullanılacak barkod + ürün adı listesini CSV veya JSON dosyası olarak yükleyin.
📂 Dosya seçmek için tıklayın (.csv veya .json)
CSV formatı (ilk satır başlık, otomatik atlanır):
barkod,urun_adi,fiyat
8690123456789,Süt 1L,45.90

JSON formatı (fiyat opsiyonel):
[{"barkod":"8690123456789","urun_adi":"Süt 1L","fiyat":45.90}]
2Kamerayla Barkod Oku
Kamerayı barkoda doğrultun. Katalogda olmayan barkodlar eklenmez, uyarı verilir.
Henüz ürün okutulmadı.
Toplam: 0 adet
3Fiş Oluştur
Fişin kime ait olduğunu girip PDF olarak indirin.
